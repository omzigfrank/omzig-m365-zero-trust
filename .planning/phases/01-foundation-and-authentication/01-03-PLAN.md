         a. Generate UUID-based database name: `tenant_${crypto.randomUUID().replace(/-/g, '').slice(0, 16)}`
         b. Create database in the elastic pool via raw SQL: `CREATE DATABASE [${dbName}] AS COPY OF [template_tenant_db]` or `CREATE DATABASE [${dbName}]` (within the elastic pool, the server handles pool assignment)

         d. Store tenant token in Key Vault via storeTenantToken

         f. Return TenantRef

       - Note: Actual Azure SQL elastic pool provisioning requires the API to have the SQL Server Contributor role or use Bicep. For local dev, just create a regular database.

    4. Create `apps/api/src/middleware/tenant.ts`:
       - `withTenantDb()` middleware using createMiddleware from hono/factory:
         a. Read X-Tenant-Id from request header
         b. If missing, return 400 with structured error
         c. Look up tenant in control plane DB (getControlPlaneDb -> query tenants table where id = tenantId)
         d. If tenant not found or isDeleted=true, return 404 with TENANT_NOT_FOUND
         e. Verify the authenticated user has access to this tenant (query tenantUserAccess table)
         f. If no access, return 403 with TENANT_ACCESS_DENIED
         g. Call getTenantDb(tenant.databaseName) to get on-demand connection
         h. Set tenantDb on context via c.set('tenantDb', db)
         i. Set tenantMeta on context via c.set('tenantMeta', tenant)
         j. Call await next()
         k. In finally block: call closeTenantDb(pool) to close the on-demand connection
       - This middleware is NOT registered globally -- it's applied to routes that need tenant context (e.g., /api/tenants/:id/*)
