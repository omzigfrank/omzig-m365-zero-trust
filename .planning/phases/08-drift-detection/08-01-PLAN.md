<objective>
Build the complete backend drift detection engine: baseline snapshot storage, audit log parser, per-area re-collector, diff engine with array-level item matching, severity classifier, drift alert DB table, in-process drift poller service, drift API routes, and SignalR push for real-time alerts.

Purpose: This transforms the platform from reactive (audit-then-fix) to proactive (continuous monitoring). MSPs will see within minutes when a tenant's security configuration drifts from its audited baseline, with a clear before/after comparison showing what changed, who changed it, and how severe the change is.
Output: Drift detection types, audit log parser, area recollector, diff engine, severity classifier, drift poller service, drift API routes, SignalR push function, two DB migrations (tenant-scoped drift_alerts + factsSnapshot; control-plane drift poll columns), and full test coverage for all components.
