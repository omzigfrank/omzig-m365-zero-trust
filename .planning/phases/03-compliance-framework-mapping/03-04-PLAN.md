    - T4 example: 6 checks (2 Critical, 2 High, 1 Medium, 1 Low). If 1 Critical fails: (4+3+3+2+1)/(4+4+3+3+2+1) = 76% = Advanced
    - Overall = weighted average across all 7 tenets
    - weakestTenet = tenet with lowest weightedPassRate
    - Thresholds parameter is optional (configurable per org)
    - Returns MaturitySnapshot with per-tenet data + overall

    Score computation:
    - frameworkScores groups findings by product and computes pass/(pass+fail)*100 per framework
    - Handles edge cases: all pass, all fail, all na, empty findings

Types to export:
```typescript
export type MaturityLevel = 'Traditional' | 'Initial' | 'Advanced' | 'Optimal';
export interface TenetMaturity {
  tenet: string;          // 'T1'..'T7'
  tenetName: string;      // Full tenet name
  totalChecks: number;
  passedChecks: number;
  failedChecks: number;
  passRate: number;        // 0-100 unweighted
  weightedPassRate: number; // 0-100 severity-weighted
  maturityLevel: MaturityLevel;
}
export interface MaturitySnapshot {
  tenets: TenetMaturity[];
  overallWeightedAverage: number;
  overallMaturityLevel: MaturityLevel;
  weakestTenet: TenetMaturity;
}
export interface MaturityThresholds {
  traditional: number; initial: number; advanced: number; optimal: number;
}
```

Constants:
- `SEVERITY_WEIGHTS: Record<string, number> = { Critical: 4, High: 3, Medium: 2, Low: 1 }`
- `DEFAULT_THRESHOLDS: MaturityThresholds = { traditional: 0, initial: 40, advanced: 70, optimal: 90 }`
- `TENET_NAMES: Record<string, string>` mapping T1-T7 to full names (e.g., T1 -> "All Resources")

Functions:
- `calculateMaturityLevel(weightedPassRate: number, thresholds?: MaturityThresholds): MaturityLevel`
- `calculateMaturitySnapshot(ztaFindings: Array<{ rating: string; severity: string; nist800207Tenet?: string }>, thresholds?: MaturityThresholds): MaturitySnapshot`
  - Groups findings by nist800207Tenet
  - Computes severity-weighted pass rate per tenet
  - Computes overall weighted average across all tenets
  - Identifies weakest tenet

export function computeFrameworkScores(findings: Array<{ product: string; rating: string }>): Record<string, { total: number; pass: number; fail: number; warn: number; na: number; score: number }>
